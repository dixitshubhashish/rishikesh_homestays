## 🗺️ Stays guide (Rishikesh & Haridwar)

- **2,700+ stays** across Rishikesh and Haridwar with "best of" pages by type (hotels, homestays, resorts, hostels, dharamshalas…), size (Studio–3 BHK+) and theme (Ganga view, pet-friendly, pool…), plus "stay near" pages for 14 landmarks (Triveni Ghat, Laxman Jhula, Har Ki Pauri, AIIMS…).
- Every stay page captures the guest's details first, then (where verified) sends them to the stay's booking page — Booking.com via our affiliate link — or to WhatsApp. Our own homestays (Advaitam, Elysium, Yoga Retreat at the Ganges) are pinned first everywhere.
- Guides: Kumbh 2027, Kedarnath Yatra, **Driving from Delhi** (Delhi–Dehradun Expressway), and a **Bike & Taxi Rental** page (bikes starting ₹700 onwards a day) with an enquiry form.
- Data lives in BigQuery (directory snapshot + an internal Google Maps lodging list); pages are generated by `scripts/stays/` (see its README).

# 📦 Deployment

Deploy in minutes with Netlify.

1. Fork or clone this repository.
2. Connect the repository to Netlify.
3. Publish directory:

```
.
```

4. Build command:

```
None
```

5. Add your custom domain

```
rishikeshhomestays.com
```
