## 🌿 About

**Rishikesh Homestays** helps travelers discover premium homestays across Rishikesh, and is a travel guide to Rishikesh and Haridwar.

Whether you're planning a yoga retreat, a family vacation, a spiritual getaway, a workcation, or an adventure-filled holiday, our curated homestays offer comfort, convenience, and unforgettable experiences close to the Ganges.

## ✨ Features

- 🏡 Curated homestays near the Ganga, with Himalayan and mountain views
- 🧘 Yoga-retreat, family, couple and workcation-friendly stays
- 🗺️ A stays guide for Rishikesh and Haridwar: about 2,800 stays with "best of" pages by type (hotels, homestays, resorts, hostels, dharamshalas…), size (studio to 3 BHK+) and theme (Ganga view, pet-friendly, pool…), "stay near" pages for landmarks (Triveni Ghat, Laxman Jhula, Har Ki Pauri, AIIMS…), and pages for the searches travelers actually type. Our own homestays (Advaitam, Elysium, Yoga Retreat at the Ganges) come first everywhere.
- 📍 Maps for every stay and landmark (OpenStreetMap)
- 📞 One-click call & WhatsApp, and direct booking enquiry forms
- 🚗 Guides: things to do, places to visit, Ganga Aarti at Triveni Ghat, Kumbh 2027, Kedarnath Yatra, Driving from Delhi, and Bike & Taxi Rental (bikes starting ₹700 onwards a day)
- 📱 Fully responsive, fast static pages
- 🔍 SEO: Open Graph and Twitter cards, sitemap, robots.txt, canonical URLs, structured data

## 🚀 Technology

- Static HTML5, CSS3 and vanilla JavaScript (no framework, no build step)
- Node.js/Express dev server; serverless API functions on Vercel (enquiries, geo, currency, email OTP)
- Google BigQuery (enquiries and stays data), Resend (email)
- Stays pages generated by Python/Node scripts in `scripts/stays/`

## 🛠️ Run it locally

```bash
npm install
npm run dev      # http://localhost:3000
npm test
```

Hosting: Vercel (primary, `vercel.json`). A Netlify static deploy (publish directory `.`, no build command, `_redirects`) is kept for parity but does not run the API functions. Domain: rishikeshhomestays.com.

Developer docs: `CLAUDE.md` (rules and where things live), `docs/HANDOFF.md` (start here), `docs/ARCHITECTURE.md`, `docs/TESTING.md`, `scripts/stays/README.md`.
